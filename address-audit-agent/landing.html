与通用AI的区别

同样的基座模型，不同的可靠性。差异来自工程化约束与系统设计。

🤖 通用 AI chatbot

  • 判断标准模糊——对"有效"和"无效"的边界没有明确定义，每次回答可能不一致
  • 新对话即失忆——每次都要重新输入提示词，无法延续已有的审核规则
  • 可能编造不存在的链接作为"证据"，你无法核实它说的是不是真的
  • 回答只有一段文字——不能批量处理、不能导出表格、不能追溯每一步的判断依据

📍 地址审核 Agent

  • 五级审核标准，四类判定结果——规则明确且一致，每次回答遵循同一套框架
  • 项目级记忆——审核规则、对话上下文不会因新会话丢失，打开即用
  • 每条结论附带可点击链接——来源是高德 API 或 Bing 搜索的真实返回，工程层自动拦截编造内容
  • 上传表格或截图即得结构化报告，每一步工具调用有完整日志

工作原理

LLM 负责推理判断，工程代码负责验证约束。各层各司其职。

文本理解

LLM 解析地址格式，判断完整度。缺少门牌号就追问，乱码直接拦截。

地图定位

高德地理编码 API，返回省市区街道门牌号七级解析。门牌号级精度才判有效。

公开记录

Bing 搜索查找地址在企业信息、政府公示、新闻中的记录。地图+搜索双重确认。

结果护栏

输出前过四道关卡：工具证据存在性、URL 可溯源、结论无矛盾、格式完整。不通过则自动重新生成。

生产级可靠性

通用对话模型与可投产系统的差距不在模型，而在工程化约束。以下三项，是 Agent 区别于"提示词套壳"的关键设计。

PRODUCT · 响应时间

① 响应时间可控

用户一次上传 30 条地址，如果串行跑、或一次性阻塞调用，界面会干等几十秒、体验归零。 我们把它当作一个产品可用性问题而非单纯性能问题来设计。

□ 第 4/6 批 等待

设计巧思：① 按 5 条/批分块，全量处理不丢数据；② 每批在独立 rerun 中并行调用高德+联网搜索（省 ~1.5s/条）；③ 联网搜索走 4 级回退链（Bing API → Bing 国内版 ~0.6s → 百度 → DDG 兜底）；④ 每批实时显示「第 X/N 批」，进程永远可见、界面永不冻结。
PRODUCT · 信任

② 进度透明化

黑盒是信任杀手。用户不是等一个最终结果，而是看着它一步步得出结论—— 这既降低等待焦虑，也便于在出错时定位卡在哪一步。

PRODUCT · 准确性

③ 报错重跑与降级

高德共享 Key 有 QPS 限流，偶发"API 失败"。普通方案会直接给出错误结论； 我们把"工具可能出错"当作一等公民来处理。

设计巧思：① 单次失败自动重试 ≤3 次（指数退避）；② 仍失败则降级到联网搜索交叉验证； ③ 两级工具皆不可用 → 结论明确判为「审核失败」并写明失败原因+下一步（换 Key/转人工）， 而非模糊地判「不确定」。技术故障与"地址本身存疑"被严格区分。

可审计：产品特性而非附加功能

在客户身份识别场景，"结论如何得出"与"结论是什么"同等重要。Agent 每轮交互落盘一份结构化审计追踪： 工具调用、原始返回、错误码（如高德限流 infocode=10021）、是否降级、耗时，全部写入 audit_trace_*.json，可一键下载。

另在提示词之外增加两道规则脚本做硬约束：

  • Rule E · 搜索相关性：引用与地址零关键词重合的网页作证据，判违规并要求替换。
  • Rule F · 行政区划一致：结论省份与地图核验省份冲突时告警，防止张冠李戴。

提示词定意图，规则脚本兜底，两者解耦，换模型不影响核心可靠性。

系统级约束

不依赖单一提示词，而是系统提示词 + 工程代码双重约束。

🎯 输入输出双向约束

输入端：提示词定义了明确地址审核标准和输出结果，约束LLM 在框架内推理。输出端：ResultGuard 代码层拦截不符合规范的输出，自动重新生成。

🧪 提示词经过严格迭代

审核标准基于真实尽调场景制定。提示词经多轮人工测试和优化，更换基座模型（DeepSeek、GPT-4o 等）不影响核心判断准确率。

🔧 支持定制化场景

审核标准、完整度级别、特殊豁免规则均可按使用者的业务场景微调。修改提示词即可生效，无需改动代码。

四种使用方式

输入地址、上传表格、或者拍张照。剩下的交给 Agent。

01

粘贴地址

把地址输入对话框，Agent 自动检查完整度，不够会追问补充信息。

02

上传表格

把 Excel 或 CSV 拖进去，Agent 逐条审核。支持批量处理。

没数据？先下载示例 test_addresses.csv，上传即看效果。

03

拍照识别

对着地址截图或纸质文件拍张照或上传本地图片，OCR 提取文字后自动进入审核流程。

04

导出报告

审核结果以表格呈现，每条依据附带可点击链接。可用于合规留档。

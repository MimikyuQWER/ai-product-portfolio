WHY

传统玩家访谈的三大瓶颈

原神海外用户研究团队在规划版本内容时，需要提前了解不同区域玩家的反馈。但传统的真人访谈方式面临系统性的效率问题。

📅

排期漫长

跨国招募目标玩家平均需要 2-4 周，遇到小众群体或特定区域用户时周期更长，难以响应快速迭代的产品节奏。

👤

样本稀疏

单轮访谈通常只能覆盖 3-5 位玩家，结论缺乏统计意义。想要达到 20+ 样本量需要投入巨大的人力和时间成本。

🔀

理解偏差

不同研究员对同一批访谈记录的解读存在主观差异。同一条玩家反馈，有人解读为"对内容不满"，有人解读为"对节奏不满"。

HOW

三级回答生成体系

不同于通用 Chatbot 的自由发挥——每条回答先判断证据充分性，再选择对应的生成策略。这是这套系统区别于其他 AI 访谈工具的核心设计。

01

原文可答

检索召回相关访谈原文 → AI 做自然转述和口吻润色 → 引用原文出处。不走角色扮演，只做忠实转述。

02

证据可推演

检索访谈原文 / BI 字段 / 画像证据 → 确定可用论据 → 调用角色扮演 Skill → 基于证据推演回答。只引用本轮召回的证据，不做越界推断。

03

证据不足

不调用角色扮演 → 不强行推断 → 直接告知用户资料不足，无法回答。诚实的不确定性比胡编的回答更有价值。

FEATURES

核心功能

将用户研究员日常工作中"筛选 → 访谈 → 对比 → 提炼"的完整流程转化为可交互的 AI 工具。

🎭

28 位虚拟玩家

每位包含 UID、付费金额、游戏时长、流失原因分析、社交媒体习惯等 20+ 档案字段，基于真实玩家数据建模。

🔍

多维度筛选

国家/性别/年龄/平台/付费等级/所属游戏/冒险等级，滑块与标签组合筛选，快速定位目标群体。

💬

深度访谈

AI 基于用户档案生成角色化回答，每条回答附带可展开的"思考过程"面板，展示推理链路和信息源引用。

👥

群聊推演

多用户同时进入群聊，发送一个问题后 6 种人设类型差异化回答，模拟真实多人访谈场景。

🧬

代表用户合成

行为标签频率加权聚合，生成最具群体代表性的虚拟画像。支持对合成用户直接发起单访。

🏷️

14 种玩家原型

从真实研究数据中归纳出碎片时间逃离型、家庭陪伴型、Anime-native RPG 玩家等 14 种差异化玩家画像。

PHILOSOPHY

设计理念

产品迭代文档中沉淀的核心设计原则，指导了从 v2 到 v7 的每次决策。

🔎

信任源于透明

每条回答必须展示推理链路：用到了哪些依据、做了什么推断、存在什么风险。使用者不是在"信 AI"，而是在"验证 AI 的判断"。

📐

三级评分体系

回答结论是否一致（50分）+ 回答原因是否一致（40分）+ 语言风格和篇幅是否合适（10分）。每次 Skill 迭代后全量重跑测试集。

🔄

Agent 驱动调优闭环

AI 执行 → 全量 Benchmark 评测 → 差异分析 + 归因 → 生成优化方案 → 人工审核 → 应用修改 → 回归测试。迭代过程可量化、可回溯。

🏷️

硬标签筛选 · 软标签理解

人口学硬标签（国家/年龄/等级）用于精确筛选；3-5 个业务意义软标签（社交驱动型/竞技硬核/碎片逃离型）用于理解用户本质。

🚫

禁止"机器预习"

不能用测试集训练 AI，避免"又做选手又做裁判"。优化方向来自其他问题的反馈，测试集只用于验证是否有进步。

🎯

建立信任 = 面试逻辑

简历（数据档案）+ 沟通风格（语言润色）+ 语言内容（言之有物）+ 活人感（不 OOC）。让业务方愿意用、敢于信。

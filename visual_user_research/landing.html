1 传统模式：真人访谈真人 → 受人力与语言限制速度慢 → 专业用研团队分析写报告 → 报告完成后原始数据资产不再利用 → 业务团队只能看到「二手信息」。
2 AI 时代的机遇：AI 访谈产品提升了效率与产出量，但用研团队面对激增的访谈数据，分析能力成为新瓶颈。
3 本项目的思路：用已有访谈与 BI 数据为真实受访者建立 AI 数字分身，用研调教分析 Skill → 激活数据资产 → 业务方和管理层直接对数字分身发起对话，获取一手用户洞察。
4 目标闭环：AI 访谈真人 → 访谈结果 + BI 数据回收 → 用研产出报告并调优分析 Skill → 数字分身作为资产持续优化 → 业务团队与管理层直接对话数字分身。

三级回答生成体系

不同于通用 Chatbot——每条回答先判断证据充分性，再选择对应的生成策略。回答可追溯、可验证、可评估。

01

原文可答

检索召回访谈原文 → AI 做自然转述和口吻润色 → 引用出处。不走角色扮演，忠实还原玩家本意。

02

证据可推演

检索原文 / BI 字段 / 画像证据 → 确定可用论据 → 调用角色扮演生成回答。只引用本轮召回的证据，不越界推断。

03

证据不足

不调用角色扮演 · 不强行推断 · 直接告知资料不足。诚实的「不确定」比胡编的回答更值得信赖。

核心功能

将用户研究员「筛选 → 访谈 → 对比 → 提炼」的完整工作流，转化为可交互的 AI 工具。

🎭

虚拟玩家库

基于上千名真实玩家的访谈与 BI 数据建模，虚拟人与真人 1:1 对应，包含 UID、付费金额、游戏时长、流失原因等 20+ 档案字段。

🔍

7 维度筛选

国家/性别/年龄/平台/付费等级/所属游戏/冒险等级。滑块 + 标签组合，快速定位目标群体。

💬

深度访谈

AI 检索用户档案后角色化回答。可展开「本轮思考过程」面板，展示推理链路与信息源引用。

👥

群聊推演

多用户同时进入群聊，一个问题 → 每个 AI 根据对应真人的资料，模拟当事人的思路，尝试还原真实焦点小组调研方式。

🧬

代表用户合成

行为标签频率加权聚合，生成最具代表性的群体画像。支持对合成用户直接发起单访。（等待后续迭代，目前尚未上线）

🏷️

玩家解读与画像

对玩家进行深度解读，提炼具有业务意义的软标签（如社交驱动型、碎片逃离型、家庭陪伴型等），尝试建立差异化用户画像。每个标签可回溯到访谈原文或 BI 字段。

设计理念与品质保障

从产品迭代文档中沉淀的核心原则与质量体系，指导了 v2 到 v7 的每次决策。

信任源于透明

每条回答展示完整推理链路：用到了哪些依据、做了哪些推断、存在什么风险。使用者不是在「信 AI」，而是在验证 AI 的判断。

端到端评测：50 + 40 + 10

回答结论是否与真人一致（50分）· 推理原因是否一致（40分）· 语言风格与篇幅是否合适（10分）。每次 Skill 迭代后全量重跑测试集，确保不退化。

独立审计 Agent

主 Agent 生成回答后，独立审计 Agent 对回答质量进行二次评估。审计结果支持点赞/点踩反馈，bad case 按错误类型分类归档，针对性调优。

严禁「机器预习」

不能用测试集训练 AI——又做选手又做裁判，会导致对小样本回答很好但碰见新情况不尽人意。优化来自其他问题的反馈，测试集仅用于验证。

硬标签筛选 · 软标签理解

人口学标签用于精确筛选；3–5 个业务意义软标签（社交驱动型/竞技硬核/碎片逃离型）用于真正理解用户本质。

Agent 驱动调优闭环

AI 执行 → Benchmark 评测 → 差异归因 → 生成优化方案 → 人工审核 → 回归测试。每次迭代可量化、可回溯，不靠「感觉」判断。

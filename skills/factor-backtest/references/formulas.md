# 金融计算公式口径

> 来源: v0.4 generate_backtest_report.py, v0.9 gen_v09_report.py
> 所有因子回测必须严格按此口径，禁止自行重写

## 收益率

```
月收益率 r_t = P_t / P_{t-1} - 1
  - P_t = 月末最后一个交易日收盘价
  - 数据源: sw_index_daily_v2.parquet
```

## 累计与年化

```
累计收益 = ∏(1 + r_t) - 1
年化收益 = (1 + 累计)^(12/n) - 1
  - n = 调仓月数
  - 使用几何年化, 不用算术平均
```

## 夏普比率

```
分子 = mean(月超额) × 12          ← 算术年化超额
分母 = std(月超额, ddof=1) × √12  ← 年化波动率
月超额 = 月收益 - 无风险利率/12
无风险利率 = 10年期国债收益率 (逐月匹配) 或 2.5% 固定
```

**注意**: 分子是算术年化, 不是几何年化减无风险利率。v0.4/v0.9 已统一为此口径。

## 最大回撤

```
nav_t = ∏(1 + r_i)  (i=1..t)
peak_t = max(nav_1..nav_t)
回撤_t = (nav_t - peak_t) / peak_t
最大回撤 = min(回撤序列)
```

## 信息比率

```
分子 = mean(策略收益 - 基准收益) × 12
分母 = std(策略收益 - 基准收益, ddof=1) × √12
```

## Rank IC

```
IC_t = Spearman(因子排序_t-1, 收益排序_t)
ICIR = mean(IC) / std(IC)
IC胜率 = mean(IC > 0)
```

- 使用月末因子值 shift(1) 对齐下月收益
- `factor.resample('ME').last().shift(1)`

## 分组收益

```
每月末按因子值排序 → 分 G1~G5
G1: 6个 (最强), G2-G4: 各6个, G5: 7个 (最弱)
每组等权持有 → 下月收益 = mean(组内行业收益)
各组净值 = cumprod(1 + 月收益序列)
```

## 盈亏比

```
正收益月均值 / |负收益月均值|
```

## 换手率

```
月换手 = 本月TOP3中不在上月TOP3中的数量 / 3
月均换手 = mean(月换手序列)
```

## 下行波动率 & 索提诺比率

```
下行波动率 = std(min(r_t - r_f, 0), ddof=1) × √12
索提诺比率 = (年化收益 - r_f) / 下行波动率
  - r_f = 2.5% 固定 (年化)
  - 只惩罚下行波动, 不惩罚上行波动
```

## 卡玛比率 (Calmar Ratio)

```
卡玛比率 = 年化收益 / |最大回撤|
  - 衡量单位回撤能带来多少收益
  - 越高越好, > 0.5 为良好
```

## ddof 参数约定

```
截面 z-score 标准化: ddof=0 (总体标准差)
时间序列波动率:      ddof=1 (样本标准差)
  - 来源: 金融时间序列标准做法, 《因子投资》第3章
```

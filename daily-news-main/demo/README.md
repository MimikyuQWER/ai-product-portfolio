# AI 资讯日报 Demo

> 把分散在不同网站的 AI 新闻，整理成一份每天几分钟就能读完的中文日报。

这是一个可以独立运行的校招作品 Demo。招聘官无需注册账号、安装数据库或配置 API 密钥，只需 Node.js 和两条命令，即可查看完整界面与全部数据快照。

![AI 资讯日报阅读器界面](docs/screenshot.png)

## 30 秒了解这个项目

| 问题 | 回答 |
| --- | --- |
| 它解决什么问题？ | AI 信息来源多、更新快、重复内容多，逐个平台浏览非常耗时。 |
| 它提供什么价值？ | 将新闻聚合、去重、图片本地化和 AI 中文摘要整合为结构统一的日报。 |
| 这个 Demo 能看什么？ | 18 个日期快照、401 张本地图片、阅读与编辑、草稿、撤销、导出和可选 AI 润色。 |
| 是否需要账号或密钥？ | 不需要。只有“AI 润色”是可选能力。 |
| 数据是否实时？ | 不是。作品集版本使用固定快照，确保面试现场稳定复现。 |

完整产品的数据链路是：

```text
RSS / 网站信息源
        ↓
抓取与字段标准化
        ↓
去重、正文清洗、图片本地化
        ↓
AI 生成中文标题、摘要、价值说明和标签
        ↓
日报阅读、编辑、导出与发布
```

本目录只保留最后一段“日报体验”和必要的轻量服务。抓取器、数据库、调度器、发布账号及内部文档没有放入公开 Demo。

## 两分钟体验路线

启动项目后，可以按下面的顺序体验：

1. 在左侧切换不同日期，观察日报内容与图片均可离线加载。
2. 使用右侧目录快速跳转到“每日产品”“GitHub 项目”等栏目。
3. 点击“编辑”，修改 Markdown；草稿会按日期保存在当前浏览器。
4. 尝试撤销、重做和恢复原始快照。
5. 点击“本地导出”，复制正文、下载 Markdown 或导出独立 HTML。
6. 点击“AI 润色”，查看无密钥时的安全配置引导；配置密钥后可体验真实分段处理。
7. 将窗口缩窄，查看移动端日期选择器和导航抽屉。

## 核心功能及用户价值

### 长资讯快速阅读

- 使用清晰的栏目、标题层级和目录导航降低长文阅读成本。
- 18 个标准日期可直接切换，另保留 1 份历史归档副本。
- 401 张新闻图片已经本地化，演示不依赖第三方图床稳定性。

### 阅读与编辑合一

- 阅读模式适合浏览，编辑模式直接处理 Markdown。
- 草稿按日期保存在浏览器，不会修改固定数据快照。
- 提供最多 5 步撤销/重做，并可随时恢复原文。

### 内容可带走

- 一键复制当前 Markdown。
- 下载 Markdown，方便继续编辑或导入其他内容工具。
- 导出带样式的独立 HTML，双击即可离线阅读。

### 可选而安全的 AI 能力

- 默认不配置密钥，所有基础功能仍然可用。
- 按 Markdown 二级标题分段处理，并通过 NDJSON 返回实时进度。
- Prompt 要求保留事实、链接、图片路径和标题层级。
- 某个章节失败时保留原文，不影响其他章节。
- AI 结果只进入浏览器草稿，永远不覆盖固定快照。
- API 密钥只由本地 Node 服务读取，不会返回前端或进入构建文件。

## 产品与设计思路

这个 Demo 的目标不是堆更多后台页面，而是让第一次接触项目的人快速理解核心价值。

### 固定快照优先

作品集最重要的是稳定复现。Demo 使用真实生成结果的固定快照，即使面试现场网络不稳定，也能完整展示阅读、编辑和导出体验。页面明确标记“数据快照演示”，避免让用户误以为内容仍在实时更新。

### 内容优先的 editorial 视觉

界面采用浅色纸张感、衬线标题和克制的灰阶，让注意力集中在新闻内容而非装饰。桌面端使用“日期—正文—目录”三栏结构；窄屏下将日期改为选择器与抽屉，避免压缩正文宽度。

### 渐进式展示复杂能力

访客打开页面即可阅读，不需要先理解模型、Agent 或数据管道。编辑、导出和 AI 润色都放在正文工具栏中，需要时再展开。

### 原文永远可恢复

编辑和 AI 润色都只创建本地草稿。固定快照保持只读，这是为了降低试错心理成本，也避免 AI 结果污染原始数据。

### 安全降级，而不是整体失败

没有密钥时只关闭 AI 润色；单章节请求失败时只回退该章节；历史缺图返回本地占位图。局部问题不会让整个 Demo 失去可用性。

更完整的用户、信息架构、交互取舍和后续指标设计见 [产品设计说明](docs/PRODUCT_DESIGN.md)。

## 快速启动

### 环境要求

- Node.js 20 或更高版本
- npm（通常随 Node.js 一起安装）
- Windows、macOS 或常见 Linux 发行版

无需 Python、Docker、数据库或第三方账号。

### 安装并运行

进入 `demo` 目录：

```bash
npm install
npm run demo
```

然后访问：<http://127.0.0.1:4173>

`npm run demo` 会先检查 TypeScript 并完成生产构建，再启动轻量本地服务。

Windows PowerShell：

```powershell
cd "你的路径\daily-news-main\demo"
npm install
npm run demo
```

macOS / Linux：

```bash
cd /你的路径/daily-news-main/demo
npm install
npm run demo
```

## 可选：体验 DeepSeek 润色

没有密钥时可以跳过本节。

1. 将 `.env.example` 复制为 `.env`。
2. 在本机 `.env` 填写自己的密钥。
3. 重新运行 `npm run demo`。

```dotenv
AI_API_KEY=你的密钥
AI_API_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat
```

也可以更换为其他兼容 OpenAI Chat Completions 接口的服务。不要将 `.env` 上传到代码仓库或作品集压缩包。

## 技术实现

| 层级 | 选择 | 用途 |
| --- | --- | --- |
| 前端 | React、TypeScript、Vite | 单页阅读器、交互和生产构建 |
| 内容 | React Markdown、GFM | 渲染标题、列表、表格、链接和图片 |
| 安全 | rehype-sanitize | 过滤历史快照中的危险 HTML |
| 图标 | Lucide React | 保持工具栏图标统一 |
| 后端 | Node.js 原生 HTTP | 静态托管、健康检查和 AI 代理 |
| AI 协议 | OpenAI-compatible API | 兼容 DeepSeek 等模型服务 |
| 流式反馈 | NDJSON | 分章节返回处理进度与最终结果 |
| 草稿 | localStorage | 无账号条件下按日期保存本地编辑 |

服务默认只监听 `127.0.0.1`，不会主动暴露给局域网。

## 数据与公开边界

本项目展示的是截至 **2026 年 8 月 24 日** 的固定数据快照，不会在 Demo 中重新抓取新闻，也不伪装成实时更新服务。外部新闻标题仍链接到原始来源。

原始 `2026-05-27` 快照有 20 个未随历史数据归档的图片引用。Demo 会为这些路径返回本地占位图，避免出现破图或 404；其余 401 个原始图片均原样保留。

公开目录不包含 `.env`、真实 API 密钥、SQLite 数据库、运行日志、PRD、调度任务、发布账号、Webhook、爬虫源码或完整业务后端。

## 故障排查

**端口已被占用**：在 `.env` 加入 `PORT=4174`，重启后访问新端口。

**提示先构建**：执行 `npm run build` 后再执行 `npm start`，或者直接运行 `npm run demo`。

**图片无法显示**：不要直接双击 `index.html`，请通过 `npm run demo` 启动本地服务。

**AI 润色不可用**：检查 `.env` 文件名、API 密钥、模型余额和网络连接，然后重启服务。没有 AI 配置不影响其他功能。

**想恢复原文**：点击工具栏恢复按钮。原始快照不会被编辑或 AI 润色覆盖。

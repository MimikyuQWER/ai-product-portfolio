# Samples — 脱敏样例页面

> 本目录用于展示真实知识库系统的 **4 种页面类型**结构与 frontmatter 格式（依据 `../SCHEMA.md`）。
> 所有内容均为**中性格式示例**，已脱敏，不含任何个人隐私研究结论。

| 类型 | 文件 | 说明 |
|------|------|------|
| Entity（实体） | `entities/示例_知识实体_策略类.md` | 知识实体，含策略类扩展字段（status / 信号规则 / 回测表现） |
| Judgment（判断） | `judgments/示例_个人判断.md` | 个人观点，带 `confidence` 与正反论证、判断历史 |
| Pattern（方法） | `patterns/示例_工作方法.md` | 可复用工作方法，带 `times_used` 计数器 |
| Observation（观察） | `observations/示例_时间性观察.md` | 时间性观察，带 `data_as_of` / `data_freshness` 时效性标记 |

真实系统含 150+ 篇此类页面（量化金融 / AI 产品双领域），因隐私未随包发布；如需了解完整结构，请对照 `../SCHEMA.md` 与本目录样例。

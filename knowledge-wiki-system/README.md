## 数据流入通道

### 1. 飞书知识库同步（每日自动）

`sync_feishu.py` 通过飞书开放 API 增量同步 3 个知识空间：
- **AI 知识库**（16 篇）：Agent 记忆系统、多 Agent 集群、提示词积累、基模评测等
- **金融专业知识**（13 篇）：债券分析、财务分析、REITs 等
- **秋招暑期准备**（4 篇）：面试准备、网申文档

同步机制：OAuth 用户授权 → 递归遍历知识空间节点树 → SHA-256 内容指纹对比 → 仅写入有变更的文档 → 记录 changelog。支持 headless 模式（Windows 定时任务每日 9:00 自动运行），token 过期自动刷新。

### 2. 研报入库（PDF/PPTX → Markdown）

双工具对比择优流程：
1. **MarkItDown** 提取：微软开源，AI 增强语义提取
2. **pdfplumber** 提取：基于规则的精确文本定位 + 表格检测
3. **自动评分**：颜色值残留、空表格碎片、数字碎片、文本密度四个维度
4. **择优保留**：质量检查通过后存入 `raw/上农商资管材料/`

增强提取阶段额外处理表格（`### 📊 表格X.Y` 标记）和图片（占位符标记，附原始文件路径）。

### 3. 会话自动 Digest

每次 Claude Code 对话结束后，自动生成会话摘要写入 `inbox/`（含 session_id、topics、关键产出），供后续整理归档。

## 结构化方法：4 种页面类型

所有页面统一 YAML frontmatter，包含 `type`、`domain`、`created`、`updated` 等元数据。

| 类型 | 用途 | 示例 | 特殊要求 |
|------|------|------|---------|
| **Entity** | 知识实体（框架、策略、因子、数据源） | 资产配置投研框架、动量因子、中金固收分析框架 | 标注 `category`、`status` |
| **Judgment** | 个人判断和观点 | "宏观打分因子对行业轮动的边际贡献有限" | `confidence`（0-1）+ 支撑证据 + 反面论证 |
| **Pattern** | 可复用工作方法 | 量化策略开发前置检查清单、策略自进化迭代框架 | `times_used` 计数器 |
| **Observation** | 有时间性的观察 | 市场周度观察 2026W26 | `date`、`data_freshness` |

### 渐进式披露：单文件内分层

每个页面按三层组织，AI 按需深入：

```
L1 frontmatter   → AI 始终可见（类型/领域/时效性）
L1 大纲索引       → AI 50行内掌握全貌
L1 详细内容       → 完整知识（人类详读 + AI 需要时深入）
L2 深层导航       → 指向 raw/ 原始材料 + [[关联页面]]
```

检索逻辑：AI 先读大纲索引 → 信息够了就停 → 不够往下翻 → 还不够追 raw/。

## AI 检索与协作机制

### 交叉引用网络

所有页面用 `[[页面名]]` 做内部链接。约束：
- 每个页面至少有 1 个入站链接（无孤立页面）
- Judgment 必须链接到支撑证据来源
- 跨领域连接用 `domain` 字段区分，不建重复页面

### 时效性控制

每个含数据的页面标注 `data_as_of`（数据截止日）和 `data_freshness`（刷新频率：实时/日度/周度/月度/季度/年度/框架/快照）。AI 读取时自动检查——超过 1 个月的市场数据标注"可能已过时"。

### 数据优先级

| 优先级 | 来源 | 场景 |
|--------|------|------|
| P0 | iFinD/同花顺实时 API | 行情、估值、最新财务 |
| P1 | Wiki 结构化页面 | 框架性知识、审核后的数据 |
| P2 | raw/ 原始材料 | 研报静态快照（使用时标注时间） |

### AI 协作流程

- **摄入**（"摄入这个"）：读素材 → 总结 3 个要点确认 → 更新/创建页面 → 更新 index.md
- **沉淀**（"沉淀 wiki"）：回顾对话 → 提取判断/事实/方法 → 写入对应页面 → 检查矛盾
- **健康检查**（"整理一下"）：清 inbox 积压 → 查孤立页面 → 查矛盾判断 → 查过期数据
- **答疑**（自动触发）：检测笔记疑问句 → 查 wiki + iFinD → 给出可溯源答案

## 核心原则

1. **默认更新旧页面**，不建新页面。宁可一个厚页面，也不要很多薄页面。
2. **每条事实性陈述必须可溯源**到 raw/ 原文。不确定标注"待补充"，不用常识填空。
3. **raw/ 目录只读**，AI 不能修改原始素材。
4. **每次实质性更新后 git commit**，格式：`{操作}: {简述}`。
5. **跨领域连接是好事**——知识网络的价值在连接处。

# AI 量化投研工作台前端

这是脱敏量化研究 Demo 的前端，包含 PC 专业工作台和财富平台嵌入版。页面不读取真实行情或账号配置；合成数据用于展示和复现。

直接双击 `index.html` 可以只读查看预置结果。要验证“前端点击 → 后端计算 → 七阶段归档”，请在项目根目录运行：

```powershell
.venv\Scripts\python.exe -m portfolio_demo.backend.run_server
```

然后访问 `http://127.0.0.1:8765/`。

页面包含：

- 面向非技术读者的产品定位与价值解释；
- 可点击的研究流程架构图；
- 两种产品形态各自独立的七步研究流程；
- 真实本地回测、决策和运行历史接口；
- 模块权责、输入输出和 AI/人协作边界；
- 与真实量化研究场景对应的产品设计说明。
